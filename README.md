# strategy-bot

Телеграм-бот: стратегический разбор проектов по твоему шаблону + генерация изображений по тексту.

## Команды
- `/start` — приветствие, кратко что умеет бот.
- `/help` — подробная справка по использованию.
- `/new` — забыть загруженные файлы-материалы.
- `/review` — принудительно разобрать загруженные файлы по шаблону.
- `/img <промпт>` — сгенерировать изображение по тексту (Cloudflare Workers AI).
- `/mode cloud` — быстрый текст через Cloudflare (Llama-3.3-70B, без карты, ~секунды).
- `/mode local` — вернуть текст на локальный Ollama (приватно, ~минуты).
- Отправь `.md` / `.txt` файл — добавить его как материал для разбора.
- Просто текст (без файлов) — быстрый совет / консультация.

## Как запустить (локально)
Бот работает на твоём компьютере, поэтому должно быть запущено:
1. **Ollama** — для текстового разбора в локальном режиме (команде `/img` и режиму `/mode cloud` Ollama не нужна).
2. Сам бот: `python bot.py` в папке проекта.

Если выключишь компьютер — бот не ответит в Телеграме, пока не запустишь `python bot.py` снова.

### Режимы текста
- **local (по умолчанию):** текст генерирует локальная Ollama (`gemma3:12b`). Приватно, но медленно (~минуты на CPU).
- **cloud:** текст генерирует Cloudflare Workers AI (`CLOUDFLARE_TEXT_MODEL`, по умолчанию Llama-3.3-70B). Быстро (~секунды), бесплатно в рамках 10 000 нейронов/день, но запрос уходит на сервер Cloudflare. Переключается командой `/mode cloud` в чате.

## Сроки действия токенов
- **Cloudflare API-токен:** до **22 сентября 2026**. После этого команда `/img` перестанет работать — нужно создать новый токен (права `Account → Workers AI → Edit`) и обновить `CLOUDFLARE_API_TOKEN` в `.env`.
- **GitHub-токен:** **90 дней** от момента создания. После этого пуш в репозиторий не сработает — создай новый токен (права `repo`) и обнови его в `api-tokens.txt`.
